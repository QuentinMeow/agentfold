# Decisions — choose the future behavior

This folder contains choices that need human authority. Only files whose tracking
status is `waiting` need an answer; `folding` means an agent is already recording one.

Each file asks one clear question, explains what is true today and what future behavior
is being decided, and compares every option on the same basis. It then shows the
evidence, assumptions, confidence, rationale, and reversal conditions before putting
the agent's recommended option last. It also says exactly what happens without a
response. You can answer in your own words under `Your response`; you do not need to
edit tracking details or open the references to understand the choice.

Agents create a timing-prefixed file from `templates/queue/decision.md` and follow
`handbook/human-action-guide.md` plus `handbook/decision-guide.md`.
