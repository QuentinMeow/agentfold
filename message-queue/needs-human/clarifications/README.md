# Clarifications — correct the current understanding

This folder contains questions about human intent or an ambiguous requirement. Only
files whose tracking status is `waiting` need an answer; `folding` means an agent is
already recording one.

Each file states the agent's current understanding, names the uncertainty, compares
plausible interpretations on the same basis, and shows evidence, assumptions,
confidence, rationale, and reversal conditions before recommending an interpretation.
It also says exactly what assumption or safe path applies without a response. You can
choose an interpretation, correct it in your own words, or ask a follow-up question
under `Your response`.

Agents create a timing-prefixed file from `templates/queue/clarification.md` and follow
`handbook/human-action-guide.md`.
