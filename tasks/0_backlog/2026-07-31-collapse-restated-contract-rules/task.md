# Collapse contract rules that are restated, circular, or describe nothing that runs

**Claimed-by:** unclaimed
**Filed:** 2026-07-31, by claude, from an audit of restated and unenforced contract text
**Parent:** none
**Repository scope:** core
**Queue actions:** `message-queue/needs-agent/requests/non-blocking-pick-up-collapse-restated-contract-rules.md`

## Goal

An audit of this repository's contract files found three failure shapes that a reader
cannot resolve by reading more carefully, because the text itself has no fixed point.
This task removes them. First, contract precedence is currently circular: root
`AGENTS.md` says the closest `AGENTS.md` wins, and `handbook/AGENTS.md` says the root
wins over anything in `handbook/`, so for any file under `handbook/` the two rules cite
each other forever. Second, several contracts describe mechanisms in the present tense
that are not wired to anything — retry items are not auto-filed, guard modes are not
configurable and are specified only in a document `docs/AGENTS.md` classifies as a
proposal, and the link check is claimed to be universal while five directories are
exempt from it. Third, two ADR chains lost their linking metadata, so `memory/index.md`
and the ADR files disagree about what is still in force.

The delivery-prefix restatement — the same rule copied into nineteen files — is the
fourth shape, and it already has a filed task. This task is the parent of
2026-07-25-single-source-queue-prefix-rule, which is widened from the five templates
it originally scoped to every live contract that restates the rule.

## Acceptance criteria

- [ ] Contract precedence is stated in exactly one place and terminates: no file states
      a precedence rule that points at another file whose precedence rule points back.
      Verified by reading root `AGENTS.md`, `handbook/AGENTS.md`, and
      `handbook/principles/folder-as-a-service.md` in sequence
- [ ] No live contract asserts in the present tense that retry items are auto-filed,
      that guard modes exist, that a third branch lane is defined in
      `handbook/git-workflow.md`, or that the link check is unqualified. Each such
      sentence is either deleted or made conditional on the thing that would make it
      true, and no new mechanism is invented to satisfy one
- [ ] `handbook/adoption-guide.md` no longer sends a reader to a document that does not
      exist
- [ ] `templates/memory/adr.md` defines `**Amends:**`/`**Amended-by:**` for a partial
      reversal, `memory/AGENTS.md` states when to use it, and no existing decided ADR
      has any sentence of its Context, Decision, Alternatives, or Consequences changed
- [ ] `memory/index.md` marks every ADR whose clauses were overturned, is regenerated by
      `python3 automation/reconcile/reconcile.py --fix-index`, and is never hand-edited
- [ ] Every rule deleted as a restatement is still reachable from a natural starting
      point by following links, and `verification.md` records the before-and-after text
      for each one
- [ ] `python3 automation/reconcile/reconcile.py --check` exits 0 with zero blocking
      findings, and `python3 automation/run_tests.py` passes, both with real output in
      `verification.md`
- [ ] Every `AGENTS.md` and `SKILL.md` stays within its line budget
- [ ] `design.md` carries a complete `## Core fit` receipt, because this touches
      `templates/`, `automation/`, `skills/`, and several `AGENTS.md` files
