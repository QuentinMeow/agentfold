# Name the repo "AgentFold"

**Status:** decided
**Date:** 2026-07-22
**Decided-by:** agent (naming explicitly delegated by owner)
**Description:** Repo is named AgentFold — folders + "bring agents into the fold"; harness-family names were saturated
**Review-by:** 2027-01-22

## Context

The repo needs a memorable GitHub-facing name. A survey (2026-07-22) found every
`*harness*` name saturated (20k+ matches, several large incumbents, two direct
competitors using "repo harness" pitches), `agent-native` taken by a 3.8k-star project,
and "vibe" aging poorly.

## Decision

**AgentFold.** Effectively unclaimed (6 trivial matches), short, typeable, and carries
the design in the name: *folders* are the core primitive, and "bring your agents into
the fold" frames the team-of-agents pitch. Tagline: folders as services · files as
messages · systems over instructions.

## Alternatives considered

- **anthill** — best story (stigmergy), lost on searchability (common word); the
  stigmergy hook was kept in the README instead.
- **bullpen / swarmshop / gitcrew** — available but weaker ties to the folder primitive.
- **folder-as-a-service** — kept as the principle name; too descriptive for a repo name.

## Consequences

Revisit only if a name collision with real traction appears before first release.
